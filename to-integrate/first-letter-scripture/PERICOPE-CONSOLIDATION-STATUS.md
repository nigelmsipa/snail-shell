## Consolidation Strategy

### Methodology
1. **Respect narrative/theological boundaries** - Don't split meaningful units
2. **Target 6-12 verses per pericope** - Optimal for memorization
3. **2-3 pericopes per chapter avg** - Most chapters need subdivision
4. **Evocative titles** - Max 8 words, memorable anchors
5. **Complete verse coverage** - No gaps, no overlaps

### Example: Numbers Consolidation

**Before**:
```
36 pericopes (1 per chapter)
Average: 35.8 verses/pericope
Problem: Ch 7 has 89 verses, Ch 26 has 65 verses
```

**After**:
```
86 pericopes
Average: 26 v/p (improved but not optimal)
Ch 7: Split into 3 units (11, 36, 42 verses)
Ch 26: Split into 3 units (27, 24, 14 verses)
```

**Still needed**: Further subdivision for multi-chapter units

## Technical Notes

### Database Schema
Current `bible_pericopes` table supports:
- `id` - Unique identifier
- `book_id` - Foreign key to `bible_books`
- `chapter` - Chapter number
- `verse_start` - Starting verse
- `verse_end` - Ending verse
- `name` - Pericope title
- `subtitle` - Optional subtitle
- `display_order` - Sorting order
- `verse_count` - Calculated (verse_end - verse_start + 1)

This schema supports the consolidation work perfectly - no schema changes needed.

### Import Process
Uses `import_complete_bible.js`:
1. Delete existing pericopes for book
2. Format pericope objects
3. Insert with RLS policies
4. Verify import success

### Validation
Audit script can verify:
- Total verse coverage (should equal book's total verses)
- No overlaps (verse ranges don't cross)
- No gaps (end verse of one = start of next)
- Proper average (6-12 target)
