## Key Design Lessons

### What Went Wrong

1. **No verse density constraints** during generation
   - Result: Books averaging 4.0 to 5.3 verses
   - Should have enforced 6-12 verse minimum

2. **Overly granular theological divisions**
   - Result: Every minor thought became a pericope
   - Should have prioritized memorization ergonomics

3. **Inconsistent quality control**
   - Some books (Obadiah) are perfect
   - Others (Song of Solomon) are disaster
   - Need systematic review before declaring "complete"

4. **Title length not enforced**
   - 143 titles exceed 8 words (some up to 16!)
   - Generation scripts should validate title length

### What to Do Differently

1. ✅ **Set hard constraints:**
   - Minimum 5 verses per pericope (preferably 6+)
   - Maximum 8 words per title
   - Target 6-12 verses average per book

2. ✅ **Automate validation:**
   - Run audit script after generation
   - Don't declare book "complete" until PASS status
   - Iterate until quality standards met

3. ✅ **Prioritize memorization:**
   - Larger chunks = less cognitive overhead
   - Evocative titles > descriptive titles
   - User experience > theological precision

4. ✅ **Review before import:**
   - Manual spot-check of generated pericopes
   - Verify verse density distribution
   - Check for orphans before committing
